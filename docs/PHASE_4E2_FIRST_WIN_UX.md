# Phase 4E-2: First-Win UX & Supportive Tone

## Tone Principles
- **No Guilt, No Shame**: Never use terms like "addicted", "failed", "wasted time", or aggressive red banners.
- **Micro-Steps**: Focus on simple 1-minute positive friction challenges (10 squats, 30s breathing, 5m reading).
- **Clear Agency**: User explicitly chooses whether to **USE MY TIME** (start session immediately) or **SAVE FOR LATER** (keep earned minutes in wallet).

## First-Win Copy Matrix

| Stage | UI Element | Copy |
|---|---|---|
| Before First Win | TodayScreen Card | "YOUR FIRST WIN: Complete one small challenge today. Build a small pause between impulse and action." |
| Challenge Completion | Celebration Card | "+10 Minutes Screen Time Earned. What would you like to do with your earned time?" |
| Choice: Use | Primary Button | "[ USE NOW (Start Session) ]" |
| Choice: Save | Secondary Button | "[ SAVE FOR LATER ]" |
| After First Win | TodayScreen Card | "FIRST WIN COMPLETE ✓: You interrupted one distraction today. 10 Bodyweight Squats • +10m saved" |
