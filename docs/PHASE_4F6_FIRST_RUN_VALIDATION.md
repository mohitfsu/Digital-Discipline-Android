# Phase 4F-6: Permission & First-Run Release UX Validation

## First-Run User Experience Flow
1. **Fresh Install Launch**: Splash screen transitions smoothly to Mode Selection without latency spikes.
2. **Permission Education**: Onboarding screens explain why Accessibility is needed with zero misleading claims.
3. **Settings Navigation**: User is routed directly to system Accessibility settings.
4. **Active State Verification**: Shield indicator surfaces `PROTECTION ON` upon service connection.
5. **Denial Recovery**: If permission is denied or revoked, UI presents honest `PROTECTION OFF` state with simple re-enable CTA.
