# Phase 4E-2: Privacy & Zero Surveillance Guarantees

## Data Boundaries
- **Stored Locally**: `state`, `planId`, `completedAt`, `earnedSeconds`, `usedSeconds`, `savedSeconds`, `actionTitle`.
- **Never Collected**: Keystrokes, chat messages, screen contents, camera, microphone, URLs, contacts, or location.
- **100% Offline**: All First-Win state transitions and wallet mutations execute purely on-device without cloud network calls.
