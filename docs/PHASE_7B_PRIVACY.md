# PHASE 7B — PRIVACY & DATA MINIMIZATION

---

## 1. Zero-Surveillance Compliance
- **Zero Raw Timestamps**: Only the timestamp of the last aggregate update is stored.
- **Zero Event Payloads**: 0 screenshots, keystrokes, URLs, audio, camera, location, or messages.
- **Backup Policy**: Excluded from Android cloud backups (`allowBackup="false"`) to prevent telemetry syncing across devices.
