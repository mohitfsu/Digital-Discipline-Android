# Phase 4E-4: Goal Continuity & Goal Integrity Anchoring

## Goal as Central Anchor
- Distraction reduction is purely the *mechanism*; the user's life goal (e.g. *Get fitter*, *Read more books*) is the *anchor*.
- The UI persistently reflects this relationship.
- Changing a goal requires explicit confirmation and preserves all historical telemetry, wallet balances, and habit momentum logs.
