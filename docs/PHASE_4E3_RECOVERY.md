# Phase 4E-3: Recovery Model & Resilience

## Deterministic Recovery Detection
A recovery occurs when:
1. A user had previous meaningful activity ($\text{day}_{t-k}$ active).
2. Followed by 1 or more missed days ($\text{day}_{t-j}$ missed).
3. The user completes a meaningful intervention on day $t$.

## Recovery Philosophy
- Returning to focus after a quiet day is a key indicator of long-term habit formation.
- UI highlights: "🌱 Good recovery. Coming back after a quiet day builds lasting discipline."
- Adds $+8$ points per recovery to Habit Momentum (up to $+15$ pts max).
