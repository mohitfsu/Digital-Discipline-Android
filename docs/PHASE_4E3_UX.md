# Phase 4E-3: Calm UX & Anti-Gamification Principles

## Core Design Principles
- **No Streaks**: No fire emojis, no countdown timers to save streaks, and no shame language.
- **Supportive Tone**: Acknowledge quiet days neutrally ("Today was quieter") and celebrate recovery warmly ("You're back. One small action is enough.").
- **Clear Information Hierarchy**:
  1. Today's goal & progress
  2. Next micro-action
  3. Earned time wallet
  4. Habit momentum
  5. Supporting behavioral insights
