# Phase 4E-4: Long-Term Weekly Continuity Cycle

## Continuous Progression Model
- **Week 1**: First-Run learning and 7-day momentum loop.
- **Week 2+**: Ongoing active routine with periodic weekly retrospectives.
- **Week Progression**: Dynamically increments ($1, 2, 3, \dots$) upon user confirmation.
- **Zero Re-Onboarding**: The user stays directly in their primary `TodayScreen` flow without redundant setup wizards.
