# Phase 4E-7: UX Failure States & Graceful Degradation

## Graceful Recovery Patterns
1. **Missing Accessibility**: Displays clear, non-technical instructions to enable service in settings.
2. **Missing Notification Permission**: Operates silently without alert banners or intrusive popups.
3. **Insufficient Wallet Minutes**: Clarifies that completing a quick challenge is needed before spending time.
4. **Database or Process Restarts**: Re-evaluates state cleanly without technical error dialogs.
