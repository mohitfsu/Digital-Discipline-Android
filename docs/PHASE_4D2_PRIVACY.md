# Phase 4D-2: Privacy & Non-Surveillance Boundaries

## 1. Zero Surveillance Boundary
Digital Discipline strictly rejects surveillance mechanisms.

---

## 2. Forbidden Operations (100% Excluded)
- Keystroke logging / Accessibility text harvesting (`canRetrieveWindowContent = false`)
- Screen recording or screenshot capture
- Background location tracking
- Reading private chat messages, emails, or notifications
- Browser URL tracking or DNS inspection

---

## 3. Permitted Local Metadata
- Self-configured goals, targets, and progress records
- Aggregated daily foreground usage statistics (via Android OS `UsageStatsManager`)
- Locally executed challenge timestamps and completion statuses
- Monotonic earned time wallet ledger
