# Phase 4E-2: Today Screen First-Win Experience

## Visual Hierarchy
On `TodayScreen`, the First-Win card occupies the top coaching slot directly above the Primary Goal Card.

### 1. Active State (Before First Win)
- **Visual**: Subtle slate card with cyan border and "🌱" icon.
- **Copy**: "YOUR FIRST WIN: Complete one small challenge today."
- **Action**: 1-tap navigation directly into the first pending daily micro-action.

### 2. Completed State (After First Win)
- **Visual**: Muted emerald container with green border and "✓" icon.
- **Copy**: "FIRST WIN COMPLETE ✓: You interrupted one distraction today."
- **Metrics**: Displays the completed replacement friction name and `+Xm used` or `+Xm saved`.
- **Calm UX**: Does not display fake streak flames, coins, or gamified urgency.
