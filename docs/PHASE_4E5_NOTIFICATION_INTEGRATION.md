# Phase 4E-5: Smart Notification Integration

## Notification Behavior by Goal Lifecycle State
- **`ACTIVE`**: Standard notification governance applies (`MINIMAL`, `BALANCED`, `HELPFUL`).
- **`PAUSED`**: Goal-specific focus prompts and action reminders are suppressed.
- **`COMPLETED`**: Goal-specific focus notifications are silenced.
- **`REPLACED`**: Previous goal notifications are permanently silenced.
