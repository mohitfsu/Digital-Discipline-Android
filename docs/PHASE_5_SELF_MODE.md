## Focused, Minimal & Calm Habit Architecture

---

## 1. Minimal Self Mode Architecture
Self Mode simplifies user interaction into 4 core activities:
1. **Define Primary Goal**: Set habit title and daily target count.
2. **Select Protected Apps**: Search and pick distracting apps directly from installed device applications.
3. **Select Positive Friction**: Pick intervention challenge from the 35-item catalog.
4. **Earn & Continue**: Moment-of-distraction intervention that deposits earned time into `EarnedTimeWalletService`.

Advanced historical metrics (Habit Momentum, Journey, Weekly Review) are organized cleanly as secondary navigation items.
