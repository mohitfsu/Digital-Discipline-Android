# Phase 4C-1 — Fast Onboarding UX & Plan Review

## 1. Fast Onboarding Flow (<60s)
1. **STEP 1: Goal Intent**: User selects from 8 visual Goal Template cards (Get Fitter, Study More Consistently, Be More Productive, Be More Mindful, Read More Books, Wind Down Better, General Wellbeing, Something Else).
2. **STEP 2: Distraction Apps**: Recommends top distraction apps for category. User selects 1–5 apps.
3. **STEP 3: Replacement Habit**: Filtered list of positive friction actions tailored to the chosen goal.
4. **STEP 4: Reward Economics**: User selects reward level (LIGHT, STANDARD, STRONG).
5. **STEP 5: Explicit Review (`SelfPlanReviewScreen`)**: Complete plan summary with `[ START THIS PLAN ]` or `[ EDIT PLAN ]`.

---

## 2. Returning User Protection
- Existing users who completed onboarding are never forced through setup again.
- Existing plans are preserved and editable directly from the Self Dashboard.
