# Phase 4D-2: Action-Oriented UX & Flow Principles

## 1. Primary Action Hierarchy
When the user opens Digital Discipline, the hierarchy immediately directs attention to positive action:
1. **Contextual Greeting & Date**: Calm orientation.
2. **Today's Goal**: Visual progress bar, percentage, remaining units.
3. **NEXT ACTION (Primary CTA)**: Visually prominent card with bold `[ START ACTION ]` button.
4. **Today's Actions Timeline**: Checkmarked history of completed action segments.
5. **Earned Time Wallet**: Available minutes, active session indicator.
6. **Recent Wins**: Dynamic achievements.
7. **Daily Reflection**: Low-friction mood & helper check-in.

---

## 2. Calm, Non-Punitive Feedback
- **Missed Day Handling**: If yesterday's goal was incomplete, today starts as a fresh clean slate. No carried-over debt, no guilt messaging, and no artificial target spikes.
- **Supportive Tone**: Completing actions feels like steady progress rather than an obligation.
- **No Gamification Overload**: Zero meaningless XP, coins, or intrusive badges.
